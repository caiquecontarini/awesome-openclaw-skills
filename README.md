## ⚙️ Como Instalar uma Skill

```bash
# 1. Copie a pasta da skill para o diretório do seu agente
cp -r skills/nome-da-skill /seu/openclaw/skills/

# 2. Reinicie o agente para carregar a nova habilidade
# 3. Confirme com o agente: "Liste suas skills disponíveis"
```
